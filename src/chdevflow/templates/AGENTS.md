# Instruções aos agentes — Método C.H.

1. Leia `docs/PROJETO.md`, `docs/STATUS.md`, `docs/CH/PROTOCOLO_AGENTES.md` e a Fatia W autorizada.
2. Identifique baseline SHA, branch, limites de escopo e nível CH de autonomia.
3. Não reinterprete solicitações vagas como permissão para merge, deploy ou operações destrutivas.
4. Trabalhe em branch curta/worktree isolada. Faça testes e reporte evidências.
5. Entregue Draft PR e espere decisão humana para integrar. Segredos nunca entram em prompts ou logs.
