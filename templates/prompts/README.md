# Trilha auditável de prompts

Organizar por `prompts/W-XX/01-missao-codex.md`, `02-missao-agy.md`, `03-auditoria-chatgpt.md`.

Cada prompt inclui: Issue, objetivo, base SHA, arquivos permitidos, arquivos proibidos, autonomia CH, testes esperados, parada e saída esperada.

**Não versionar:** senhas, tokens, dados pessoais, conteúdo confidencial, respostas privadas da IA ou históricos completos desnecessários. Dados sensíveis devem ser redigidos. O prompt é evidência da missão, não substituto do código ou das decisões.
